# Changelog

## [1.0.0] - 2026-10-25

Клиент переписан под новый API сервера. Несовместим с 0.x.

### Изменено
- Доступ по API-ключу `asg_…` в заголовке `X-API-Key` вместо `user_id` и пароля.
- Все запросы идут на `/api/...`; адрес сервера задаётся явно, по умолчанию его нет.
- Ошибки — исключения (`AuthenticationError`, `RateLimitError` и др.) с кодом,
  текстом и `request_id` сервера, а не словари с ключом `error`.
- Ответы — `GenerateResult` и `Model` вместо словарей.
- Таймаут ответа 360 секунд вместо 30: модели рассуждают минутами.
- HTTP через `httpx` вместо `requests`; Python 3.9+.
- Сборка через `pyproject.toml` (hatchling), версия задаётся в одном месте.

### Добавлено
- `AsyncClient` с теми же методами.
- `ask()`, `me()`, `health()`; `GenerateResult.sources` — ссылки поиска как
  пары заголовок и адрес.
- `settings.py`: ключ и адрес из `G_API_KEY` и `G_API_URL` в окружении или `.env`.
- Файлы как пути или пары `(имя, содержимое)`; несуществующий путь — ошибка, а
  не молчаливый пропуск.
- Тесты.

### Удалено
- Регистрация (`register()`, `reg()`), пароль и `auto_register`.
- Модуль `core/settings.py` и функции `generate()` и `clear_context()` уровня
  модуля, работавшие через него.
- `setup.py`, `MANIFEST.in`, `requirements.txt` (был в UTF-16).

## [0.1.0] - 2024

### Добавлено
- Класс `Client` для удобной работы с API
- Автоматическая регистрация пользователя при создании клиента
- Валидация URL сервера
- Улучшенная обработка ошибок
- Метод `get_answer()` для получения только текста ответа
- Поддержка установки через pip
- Документация и примеры использования

### Улучшено
- Рефакторинг кода для лучшей читаемости
- Убраны print-выводы, заменены на возврат ошибок
- Добавлены таймауты для HTTP-запросов
- Улучшена типизация
- Оптимизированы зависимости (только requests)

### Исправлено
- Правильная обработка ошибок в request.py
- Корректное закрытие файлов в finally-блоках
